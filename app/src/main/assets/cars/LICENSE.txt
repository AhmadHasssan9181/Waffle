Waffle 3D navigation models
==========================

Everything in this folder is an original Waffle asset. It is generated procedurally by
`tools/cars/generate_models.py`, which builds the meshes, writes the shared palette atlas and
exports self-contained glTF 2.0 binary files.

Files
-----
- sedan-sports.glb   — sports sedan
- suv-luxury.glb     — luxury SUV
- truck-flat.glb     — crew-cab pickup
- motorcycle.glb     — sportbike with a 3D rider
- bicycle.glb        — bicycle with a 3D cyclist
- walker.glb         — pedestrian in a static pose (frame 0 of the walk cycle)
- colormap.png       — shared 512x512 material palette atlas used by every model
- LICENSE.txt        — this notice

Regenerate everything (models, walk frames and puck sprites) with:

    python tools/cars/generate_models.py
